One model. A pie is a command — the addon already registers every pie as PieMenu_<name> — so a slot is just an ordered list of (condition → command), and some commands open pies. Slot 3 below opens Surface tools on a face and Edge tools on an edge: one slot, two pies, same mechanism as any conditional tool. The ring-and-chevron look is derived from what the slot resolves to right now, never declared. The map on the left shows every possible route with its condition; a pie referenced from several places is one pie (↩ marks the repeats).
